# MHTalk Google Play listing draft

## App name

MHTalk

## Short description

Stable voice rooms, private calls, chat, camera and screen sharing.

## Full description

MHTalk keeps friends connected through a clean mobile experience designed for long voice sessions.

- Join the public Main channel or create a private room with a short invite code.
- Keep calls alive in the background with automatic connection recovery.
- Use microphone, camera and Android screen sharing with clear controls.
- Send text, emoji, voice notes, photos, videos and files.
- Reply to, edit and delete your messages.
- Create a profile with a cropped static or animated avatar and biography.
- Control each participant's voice and screen-share audio separately.
- Report messages or users and block unwanted participants.

MHTalk uses the same room system as the Windows desktop edition, so phone and PC users can join each other wherever they are.
