# Friend test: Ankara ↔ Baghdad

1. Install the Windows test build on both computers.
2. Both users open MHTalk and enter the identical room name, for example
   `ankara-baghdad-test`.
3. Use headphones. This avoids acoustic echo while both microphones are active.
4. Press **Join room**, grant microphone access, then speak in turn.
5. For a recovery test, temporarily disable Wi-Fi on one computer for a few
   seconds, restore it, and confirm that the voice room reconnects by itself.

This test build uses LiveKit Cloud's development token server. It is suitable
only for private testing; before a public release it must be replaced with the
project's authenticated token Worker.
